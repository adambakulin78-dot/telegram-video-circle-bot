# Telegram Video Circle Bot

Telegram-бот, который конвертирует обычные видео и фото в видеосообщения (кружки). 
*Примечание: это демонстрационная версия проекта. Коммерческая логика (монетизация, база данных) исключена из публичного доступа.*

## 🛠 Технологии
* Python
* Aiogram (или Telebot)
* FFmpeg (для обработки медиа)

## ✨ Возможности (Демо-версия)
* Конвертация видео длиной до 2 минут и весом до 20 МБ.
* Загрузка видео как по прямой ссылке, так и файлом.
* Добавление текста, музыки и спецэффектов.
* Автоматическая сборка всех элементов и отправка готового кружка.

## 🚀 Установка и запуск
1. Клонируйте репозиторий.
2. Установите зависимости: pip install -r requirements.txt
3. Создайте файл .env и добавьте токен: BOT_TOKEN=ваш_токен
4. Запустите бота: python main.py
