Telegram Video Circle Bot

Telegram-бот, который автоматически конвертирует обычные видео и фотографии в видеосообщения (кружки).

Примечание: это демонстрационная версия проекта. Коммерческая логика (обработка успешных платежей Telegram Stars, база данных пользователей) исключена из публичного доступа в целях безопасности.

Моя роль в проекте

Изначальный каркас кода был сгенерирован с помощью ИИ (Claude Code). Моя задача заключалась в развертывании, доработке и интеграции функций:

· Настройка и развертывание бота на Linux-сервере (Systemd).
· Интеграция платежной системы (Telegram Stars) и системы подписок.
· Настройка базы данных (SQLite) для хранения профилей пользователей.
· Тестирование и отладка медиа-обработки (FFmpeg).

Стек технологий

· Язык: Python
· Библиотеки: Aiogram 3 (асинхронный фреймворк)
· Медиа: FFmpeg (обработка видео и аудио)
· База данных: SQLite
· Инфраструктура: Linux, Systemd

Как запустить (Демо-версия)

1. Клонируйте репозиторий:
   git clone https://github.com/adambakulin78-dot/telegram-video-circle-bot.git
2. Установите зависимости:
   pip install -r requirements.txt
3. Создайте файл .env в корневой папке на основе .env.example и добавьте токен:
   BOT_TOKEN=ваш_токен_от_BotFather
4. Запустите бота:
   python src/bot_demo.py
